\begin{abstract}
A \abstdefterm{path coloring} of a graph $G$ is a vertex coloring
of $G$ such that each color class induces a disjoint union of paths.
We present two efficient algorithms
to construct a path coloring of a plane graph.

The first algorithm, based on a proof of Poh, %\cite{Poh1990}
is given a plane graph, and
produces a path coloring of the given graph
using three colors.

The second algorithm,
based on similar proofs
by Hartman % \cite{Har1997}
and \v{S}krekovski, %\cite{Skr1999}
performs a list-coloring generalization of the above.
The algorithm is given a plane graph and an assignment of lists of
three colors to each vertex, and it
it produces a path coloring of the given graph
in which each vertex receives a color from its list.

Implementations are available for all algorithms that are described.
\end{abstract}

\section{Introduction}

All graphs will be finite and simple. See West~\cite{Wes2000}
for graph theoretic terms.

A graph is
\defterm{planar} if it may be drawn in the plane by mapping
each vertex to a point, and each edge to a simple arc between
its incident vertices such that the arcs intersect only at their
endpoints. A \defterm{face} is a region
of the plane not containing any point of the drawing; we'll
refer to each face by the subgraph drawn on
its border. 
A \defterm{(combinatorial) embedding} is an equivalence
class of drawings determined by the circular ordering of edges
around each vertex. A \defterm{plane graph} is a planar graph
with a fixed embedding. Subgraphs of a plane graph are
plane graphs with the inherited embedding.

A \defterm{path coloring}
is a (vertex) coloring where each color class induces a disjoint union of
paths.
A graph $G$ is \defterm{path $k$-colorable} if $G$
admits a path $k$-coloring (a path coloring using at most $k$ colors).
A \defterm{list assignment}
$L$ of a graph $G$ maps each $v\in V(G)$ to a finite set of colors $L(v)$.
An \defterm{$L$-list-coloring} is a
coloring $c$ such that $c(v)\in L(v)$ for each $v\in V(G)$.
A graph is \defterm{path $k$-choosable} if it admits a path $L$-list-coloring
for every list assignment $L$ with at least $k$ colors in each list,
i.e. $|L(v)|\ge k$ for each $v\in V(G)$.


Broere \& Mynhardt conjectured~\cite[Conj.~16]{BrMy1985}
that every planar graph is path $3$-colorable.
This was proven independently by Poh~\cite[Thm.~2]{Poh1990}
and Goddard~\cite[Thm.~1]{God1991}.

\begin{theorem}[Poh 1990, Goddard 1991]\label{T:planar3c}
If $G$ is a planar graph,
then $G$ is path $3$-colorable.\ggcnopf\end{theorem}

It is easily shown that the ``$3$'' in Theorem~\ref{T:planar3c}
is best possible.
In particular, Chartrand \& Kronk~\cite[Section~3]{ChKr1969}
gave an example of a planar graph whose vertex set cannot be partitioned
into two subsets, each inducing a forest.

Hartman~\cite[Thm.~4.1]{Har1997}
proved a list-coloring generalization of Theorem~\ref{T:planar3c}
(see also Chappell \& Hartman~\cite[Thm.~2.1]{ChHa2017prep}).
Essentially the same coloring technique was used by
\v{S}krekovski~\cite[Thm.~2.2b]{Skr1999}
to prove a result slightly weaker than Theorem~\ref{T:planar3}.

\begin{theorem}[Hartman 1997]\label{T:planar3}
If $G$ is a planar graph,
then $G$ is path $3$-choosable.\ggcnopf\end{theorem}

We discuss two path coloring algorithms
based on proofs of the above theorems.

In Section~\ref{S:representation} we outline our graph representations
and the basis for our computations of time complexity.

Section~\ref{S:path_color} covers an algorithm
based on Poh's proof of Theorem~\ref{T:planar3c}.
The algorithm is given a plane graph;
it produces a path coloring of the given graph
using three colors.

Section~\ref{S:path_choose} covers an algorithm
based on Hartman's proof of Theorem~\ref{T:planar3},
along with the proof of \v{S}krekovski mentioned above.
The algorithm is given a plane graph
and an assignment of a list of three colors to each vertex;
it produces a path coloring of the given graph
in which each vertex receives a color from its list.

Section~\ref{S:performance} provides benchmark results for
implementations of each algorithm~\cite{Bro2017}. The section also
discusses how each algorithm may be modified to benefit from parallelism.


\section{Graph Representations and Time Complexity}\label{S:representation}

A plane graph $G$ is \defterm{triangulated} (or \defterm{maximal})
if it is connected
and $n(G)\le 2$, or if every face of $G$ is a
\defterm{triangle} (a length $3$ cycle). We say $G$ is
\defterm{weakly triangulated}
if all of its interior (bounded) faces are triangles
(a triangulated graph is also weakly triangulated).

The input for each algorithm will be a weakly triangulated
plane graph $G$ with $n$ vertices and $m$ edges.
The input size will be $n$. By Euler's formula
$m\le 3n-6$, so it is equivalent use input size $m$.
Planar graphs may be
plane embedded and triangulated (by adding edges) in $\mathcal{O}(n)$ time,
see e.g. Hopcroft
and Tarjan~\cite{Hop1974} or Boyer and
Myrvold~\cite{BoMy2004}.

We will represent $G$ for computation via \textit{adjacency lists}:
a list, for each vertex $v$, of the neighbors of $v$.
A vertex will be represented by an integer $0\dots n-1$.
The order of each list represents the embedding. In algorithms
$N(v)$ will refer to the adjacency list.

Let $v\in G$ and $u\in N(v)$. Define $\nxt_v(u)\in N(v)$ to be
the neighbor counter-clockwise from $u$ around $v$,
and $\prv_v(u)\in N(V)$ to be the neighbor clockwise from $u$.
In algorithms
$\adj{v}{u}$ will be a reference to $u$'s entry in $N(v)$, i.e.
$\adj{v}{u}$ represents both $u$ and the position of $u$ within $v$'s
adjacency list;
define $\nxt(\adj{v}{u})=\adj{v}{(\nxt_v(u))}$ and
$\prv(\adj{v}{u})=\adj{v}{(\prv_v(u))}$.

Adjacency lists naturally allow $\nxt(\adj{v}{u})$ to be computed
in constant time.
However, the linear time complexity of the algorithm discussed
in Section~\ref{S:path_choose} depends on the ability to
compute $\prv(\adj{v}{u})$ and the \defterm{back reference} $\adj{u}{v}$
from $\adj{v}{u}$ in constant time as well.
Representing $N(v)$ via an array or
doubly linked list solves computing both $\nxt(\adj{v}{u})$ and
$\prv(\adj{v}{u})$, but
back references require more information.
We define an \defterm{augmented adjacency list} to be an adjacency
list that stores the pair $(u,\adj{u}{v})$ for each neighbor $u$ of $v$.
Given an adjacency list representation, an augmented
representation may be constructed in $\mathcal{O}(m)$ time. 

\begin{algorithm}\label{A:augment} Augment Adjacency Lists

\textbf{Input.} An adjacency list representation $N$ of a graph $G$.

\textbf{Output.} An augmented adjacency list representation $N^*$ of
$G$ such that for each $v\in G$, the neighbors of $v$
appear in $N^*(v)$ in the same order they appear in $N(v)$.

\textbf{Step~1.} For each $v\in G$, construct an
augmented adjacency list $N^*(v)$
with the same ordering as $N(v)$, leaving the
$\adj{u}{v}$ portion of each entry $(u,\adj{u}{v})$ in $N^*(v)$
uninitialized.

\textbf{Step~2.} For each vertex $v$, construct a list $\text{Wrk}(v)$
of vertex-reference pairs with capacity $\text{deg}(v)$. For each $v$ from
$0$ to $n-1$, iterate through
$N^*(v)$. For each neighbor $u$ in $N^*(v)$, append the pair
$(v,\adj{v}{u})$ to $\text{Wrk}(u)$,
where $\adj{v}{u}$ is a reference to $u$'s entry $N^*(v)$.

\textbf{Step~3.} For each $v$ from $n-1$ to $0$, iterate through
$\text{Wrk}(v)$. Upon reaching a pair $(u,\adj{u}{v})$ in
$\text{Wrk}(v)$, the
last element of $\text{Wrk}(u)$ will be $(v,\adj{v}{u})$;
see below. Lookup the entry $\adj{v}{u}$ in $N^*(v)$ and
initialize the back reference $\adj{u}{v}$, and vice versa.
Pop $(v,\adj{v}{u})$ from $\text{Wrk}(u)$.
\end{algorithm}

After completing Step~2 in Algorithm~\ref{A:augment} each list
$\text{Wrk}(v)$ will contain
$(u,\adj{u}{v})$ for each neighbor $u$ of $v$, sorted in increasing
order by $u$.
Suppose that $v$ is the current vertex at a given iteration of
the loop in Step~3. For each edge $uw\in E(G)$ such that
$u<w$ and $v<w$, prior iterations of the loop will have initialized the
back references for $(w, \adj{w}{u})$ in $N^*(u)$ and $(u, \adj{u}{w})$ in
$N^*(w)$, and removed $(w,\adj{w}{u})$ from $\text{Wrk}(u)$. Therefore for
each $(u,\adj{u}{v})$ in
$\text{Wrk}(v)$, the list $\text{Wrk}(u)$ will only contain entries
$(w,\adj{w}{u})$ where $w\le v$.

\section{Path Coloring}\label{S:path_color}

In this section we describe a path $3$-coloring algorithm
based on a proof by Poh~\cite[Thm.~1]{Poh1990}.

Let $C$ be a cycle in a connected plane graph $G$. If $u,v\in C$, then we define
$C[u,v]$ to be the clockwise $u,v$-path
along $C$; if $u=v$, then $C[u,u]=u$.
Define $\graphintc(C)$ to
be the subgraph of $G$ consisting of $C$ and all vertices and edges interior to
$C$; equivalently, $\graphintc(C)$ is the maximal subgraph of
$G$ with outer face $C$. Define $\graphinto(C)=\graphintc(C)-C$.

Let $P$ be a path in a plane graph $G$. If $u,v\in P$, then
we define $P[u,v]$ to be the $u,v$-path in $P$.
We also define $\graphintc(P)=P$ and $\graphinto(P)$ to be empty.

\begin{lemma}[Poh 1990]\label{L:planar3c}
Let $G$ be a biconnected, weakly triangulated plane graph with outer face
$C$. Let $c:V(C)\to S\subsetneq\{1,2,3\}$ be a $2$-coloring of $C$ such
that each color class induces a nonempty path. There exists an extension of
$c$ to a path $3$-coloring $c:V(G)\to\{1,2,3\}$ such that for each $v\in G-C$, if $vu\in
E(G)$ with $u\in C$, then $c(v)\ne c(u)$.
\end{lemma}

\begin{proof}
If $n(G)\le 3$, then $G=C$. We proceed by induction on the order of $G$. 

Suppose that $G\ne C$. Let $P_1,P_2$ be the two paths induced by the $2$-coloring
of the outer face
$C$. We may write $P_1=C[u_1,w_1]$ and $P_2=C[w_2,u_2]$ for vertices
$u_1,u_2,w_1,w_2\in C$.

Suppose that $C$ is an induced subgraph of $G$. Take
$u_3,w_3\in G-C$ such that the cycles
$u_3,u_2,u_1$ and $w_3,w_1,w_2$ are faces of $G$; note that
$u_3$ and $w_3$ are uniquely determined, but it may be that $u_3=w_3$. Since
$C$ is induced, $G-C$ is connected.
Let $P_3$ be an induced $u_3,w_3$-path in $G-C$.
Color each vertex of $P_3$ with $d\in\{1,2,3\}- S$.
Let $C_1=P_1\cup P_3\cup u_3u_1\cup w_3w_1$ and
$C_2=P_2\cup P_3\cup u_3u_2\cup w_3w_2$, see Figure~\ref{F:poh_proof} (left).
By the inductive hypothesis, the $2$-coloring of $C_1$ extends to a path
$3$-coloring of $\graphintc(C_1)$. Similarly, the coloring of $C_2$ extends to
a path $3$-coloring of $\graphintc(C_2)$.
Together these colorings form a $3$-coloring of $G$.
Since $C$, $P_3$, $\graphinto(C_1)$, and $\graphinto(C_2)$ partition $V(G)$, and no
vertex shares a color with a neighbor in a different partition,
this $3$-coloring is a path coloring satisfying the lemma.

Suppose that $C$ is not an induced subgraph. Then there
exists an edge $v_1v_2\in E(G)- E(C)$ with $v_1\in P_1$ and
$v_2\in P_2$. Let $C_1=C[v_2,v_1]\cup v_1v_2$
and $C_2=C[v_1,v_2]\cup v_1v_2$, see Figure~\ref{F:poh_proof}.
By the inductive hypothesis, $c$ extends to path
$3$-colorings of $\graphintc(C_1)$ and $\graphintc(C_2)$.
Together these colorings form a path $3$-coloring of $G$.\ggcnopf
\end{proof}

Let $G$ be a triangulated plane graph. We may trivially path $2$-color the outer
triangle. By Lemma~\ref{L:planar3c} this extends to a path
$3$-coloring of $G$.
If $G$ is an arbitrary planar graph, we may compute an embedding and add edges
to produce a triangulated plane graph $G'$. Theorem~\ref{T:planar3c}
follows immediately as any path coloring of
$G'$ is also a path coloring of $G$.

Let $G$, $C$, $P_1$, and $P_2$ be as in Lemma~\ref{L:planar3c},
and assume that $C$ is induced in $G$.
For a subgraph $H$ of $G$, let $N(H)$ be the set of
vertices in $G-H$ that have a neighbor in $H$.
Let $G_1$ be the subgraph of $\graphintc(C)$ induced by
$V(P_1)\cup N(P_1)-V(P_2)$, see Figure~\ref{F:poh_linear_0}. Let $C_1$
be the outer face of $G_1$.
Algorithm~\ref{A:poh_linear} implements Poh's algorithm in linear time
by using $P_3=C_1-P_1$ as the $u_3,w_3$-path.
Observe that $P_3$ is induced in $G$: $G_1$ is induced, so there is no chord of
$P_3$ exterior to $C_1$,
and each $v\in P_3$ has a neighbor in $P_1$, so there is no chord of $P_3$
interior to $C_1$.
To find $P_3$, we walk counter-clockwise from
$u_3$ along $C_1$.

Define $p_1:N(P_1)\to V(P_1)$ to be the map sending each $v\in N(P_1)$
to its neighbor in $P_1$ that is closest to $w_1$,
i.e. $V(C[p_1(v),w_1])\cap N(v)=\{p_1(v)\}$.

\begin{algorithm}\label{A:poh_linear} Path $3$-Color% (Neighborhood Walk)

\textbf{Input.} Let $C$ be an induced cycle
in a weakly triangulated plane
graph $G$ represented via adjacency lists.
Let $c$ be a length $n$ array
representing a $2$-coloring of $C$ such
that each color class induces a nonempty path,
respectively $P_1=C[u_1,w_1]$ and
$P_2=C[w_2,u_2]$, where $u_1,u_2,w_1,w_2\in C$. Assume that $c(v)=0$
for each $v\in\graphinto(C)$.
Let $S$ be a length $n$ array, and $\ell_1$ an integer,
such that for $v\in\graphinto(C)$, $S(v)=\ell_1$ if and only if
$v\in N(P_1)$.

The concrete input will be $G$, $c$, and $S$,
along with the tuple $(u_1, \adj{{u_1}}{u_2}, \ell_1)$.

\textbf{Output.} For each vertex $v\in\graphinto(C)$, a color in
$\{1,2,3\}$ will be
assigned to $c(v)$ such that $c$ represents a path $3$-coloring of
$\graphintc(C)$ extending the original $2$-coloring of $C$.
Moreover, if $v\in \graphinto(C)$ has a neighbor $u\in C$,
then $c(v)\ne c(u)$.

\textbf{Procedure.} Let $\adj{u_1}{u_3}:=\nxt(\adj{u_1}{u_2})$.
It may be useful to refer to Figures~\ref{F:poh_linear_0}
and \ref{F:poh_linear_1}.

\textbf{Base case.}
If $c(u_3)\ne 0$, then
$u_3=w_2$ or $u_3=w_1$. Thus $C$ is a face and we are done. 

\textbf{Recursive case.}
Suppose that $c(u_3)=0$, i.e. $u_3\in\graphinto(C)$.
Let $\ell_3:=\max_{v\in G}S(v)+1$.
Let $d\in \{1,2,3\}-\{c(u_1),c(u_2)\}$.
We'll
walk the induced $u_3,w_3$-path $P_3=C_1-P_1$,
where $C_1$ is the outer face of the subgraph $G_1$
of $\graphintc(C)$
induced by $V(P_1)\cup N(P_1)-V(P_2)$.

\textbf{Step~1.}
Let $a:=u_1$ and $z:= u_3$; here $z$ stores the current
vertex of $P_3$, and $a$ stores the neighbor of $z$
clockwise from $z$ around $C_1$.
Let $t:=\text{NULL}$ and $\adj{t}{x}:=\text{NULL}$;
here $t$ and $\adj{t}{x}$ store the last edge $tx$ visited
where $t\in P_3$ and $x\in P_2$
(the first such edge is $u_3u_2$).

\textbf{Loop~2.} We'll walk counter-clockwise
along $C_1$, coloring one vertex $z$ per iteration, and
halt after $z=w_3$.
Color $c(z)\leftarrow d$.
Find $\adj{z}{a}$ in $N(z)$ and let
$\adj{z}{v}:= \nxt(\adj{z}{a})$.
Let $b:=\text{NULL}$; here
$b$ will store neighbor of $z$ in $P_3$ that is
counter-clockwise from $z$ around $C_1$, if it exists.
Let $\adj{z}{y}:=\text{NULL}$; here
$\adj{z}{y}$ will store the last edge $zy$ visited
where $y\in P_1$.

\textbf{Loop~2.1.} We'll first consider the neighbors of
$z$ from
$\nxt_{z}(a)$ to $p_1(z)$ counter-clockwise. Each iteration
will handle one neighbor $\adj{z}{v}$.
We'll make a recursive call for each
induced cycle $C'$ we discover with $V(C')\subseteq V(P_2)\cup V(P_3)$.

\textbf{Case~2.1.1.} Suppose that $c(v)=0$, i.e. $v\in\graphinto(C)$.
If $S(v)=\ell_1$ and $b=\text{NULL}$, then $v\in P_3$ and we set
$b\leftarrow v$. Set $S(v)\leftarrow \ell_3$ and
$\adj{z}{v}\leftarrow\nxt(\adj{z}{v})$.
Repeat Loop~2.1.

\textbf{Case~2.1.2.} Suppose that $c(v)=c(u_2)$, i.e. $v\in P_2$.
If $t\ne\text{NULL}$, make a recursive call with input $(t, \adj{t}{x}, \ell_3)$
to color $\graphintc(C')$, where
$C'=P_3[t,z]\cup C[v,x]\cup tx\cup zv$;
refer to Figure~\ref{F:poh_linear_1} (left).
Set $t\leftarrow z$, $\adj{t}{x}\leftarrow \adj{z}{v}$, and
$\adj{z}{v}\leftarrow\nxt(\adj{z}{v})$. Repeat Loop~2.1.

\textbf{Case~2.1.3.} Suppose that $c(v)=c(u_1)$, i.e. $v=p_1(z)\in P_1$.
Break Loop~2.1. If $v=a$, skip to Step~2.3. Otherwise, set
$\adj{z}{y}\leftarrow \adj{z}{v}$, $\adj{z}{v}\leftarrow\nxt(\adj{z}{v})$,
and proceed to Loop~2.2.

\textbf{Loop~2.2.} We'll now consider the
neighbors of $z$ from $\nxt_{z}(p_1(z))$ to $a$ counter-clockwise.
Each iteration will handle one neighbor $\adj{z}{v}$.
We'll make a recursive call for each
induced cycle $C'$ we discover with $V(C')\subseteq V(P_1)\cup V(P_3)$.
Observe that $\adj{z}{y}\ne\text{NULL}$.

\textbf{Case~2.2.1.} Suppose that $c(v)=0$, i.e. $v\in\graphinto(C_1)$.
Assign $S(v)\leftarrow \ell_3$ and $\adj{z}{v}\leftarrow\nxt(\adj{z}{v})$.
Repeat Loop~2.2.

\textbf{Case~2.2.2.} Suppose that $c(v)\ne 0$ and $v\ne a$,
i.e. $v\in P_1$. Make a recursive
call with input $(z, \adj{z}{y}, \ell_3)$ to color $\graphintc(C')$,
where $C'=C[v,y]\cup z\cup zy\cup zv$;
see Figure~\ref{F:poh_linear_1} (middle).
Set $\adj{z}{y}\leftarrow\adj{z}{v}$ and
$\adj{z}{v}\leftarrow\nxt(\adj{z}{v})$, then
repeat Loop~2.2.

\textbf{Case~2.2.3.} 
Suppose that $v=a$. Make a recursive
call with input $(z, \adj{z}{y}, \ell_3)$ to color $\graphintc(C')$,
where $C'=C[p_1(v),y]\cup P_3[v,z]\cup vp_1(v)\cup zy$;
see Figure~\ref{F:poh_linear_1} (right).
Break Loop~2.2 and proceed to Step~2.3.

\textbf{Step~2.3.} If $b\ne\text{NULL}$, then
assign $a\leftarrow z$, $z\leftarrow b$, and
repeat Loop~2. Otherwise, $z=w_3$ and $c$ is a path $3$-coloring of
$\graphintc(C)$, so we are done.
\end{algorithm}

Given a triangulated plane graph $G$ represented via adjacency lists,
we can apply
Algorithm~\ref{A:poh_linear} as follows. First, create length $n$ integer
arrays for $c$ and $S$, initializing each entry to zero.
Let $C=v_1,v_2,v_3$ be the outer triangle of $G$,
labeled in clockwise order.
Color $c(v_1)\leftarrow 1$, $c(v_2)\leftarrow 2$, and
$c(v_3)\leftarrow 2$.
Iterate through $N(v_1)$ and mark $S(v)\leftarrow 1$ for each
neighbor $v$ of $v_1$.
Then $G$, $c$, $S$,
$(v_1, \adj{v_1}{v_3}, 1)$ form a valid input for
Algorithm~\ref{A:poh_linear}.

During Algorithm~\ref{A:poh_linear} we iterate through
$N(v)$ for each $v\in G$ exactly twice: once
to locate $\adj{z}{a}$ when
$z=v$ is colored at the start of Loop~2,
and once to iterate through $N(z)$ in Loops~2.1 and 2.2.
Therefore the time complexity is
$\mathcal{O}(n)$.

\section{Path List-Coloring}\label{S:path_choose}

In this section we describe an algorithm to path color
plane graphs such that each vertex receives a color from a specified list.
Hartman showed that this is always possible when each vertex is given a
list of $3$ colors~\cite[Thm.~4.1]{Har1997}. Around the same
time \v{S}krekovski proved a
weaker result using the same coloring
strategy~\cite[Thm.~2.2b]{Skr1999}.

In brief, the Hartman-\v{S}krekovski algorithm takes as its input a
weakly triangulated plane
graph $G$ with outer face $C$, a list assignment $L$, and two
vertices $x,y\in C$. It
assumes that $|L(x)|\ge 1$, $|L(y)|\ge 1$, $|L(v)|\ge 2$ for each
$v\in C-\{x,y\}$, and $|L(v)|\ge 3$ for each $v\in G-C$. An
induced path $P$ is colored with $d\in L(x)$,
proceeding from $x$ towards $y$ along $C[x,y]$,
such that for each $v\in P$, $d\in L(v)$. Starting from
$P=x$, the path is colored
as follows: let $z$ be the end of $P$ opposite $x$, and
$T_{z}=\{v\in N(z)\cap V(C[z,y]):d\in L(v)\}$; if $T_{z}\ne\emptyset$,
then the $v\in T_{z}$ closest to $y$ in $C[z,y]$
is colored and added to $P$, and this process is repeated with $z=v$.
After coloring $P$, the algorithm is recursively applied to each connected
component of $G-P$, using the list assignment $L'$ defined by
$L'(v)=L(v)-\{d\}$ if $v\in N(P)$, and $L'(v)=L(v)$ if
$v\not\in N(P)$. See Figure~\ref{F:hartman_overview}
for an example.

In Lemma~\ref{L:hartman3} below, we provide a different proof of Hartman's
result, organized in such a way that it immediately
describes a linear time algorithm for graphs
represented as in Section~\ref{S:representation}.
If $x=z$, then our $G,x,y$ match
those in Hartman's \cite[Lemma~4.2]{Har1997}, but we assume
that $G$ is biconnected;
we follow a similar procedure to color a path
$P$ clockwise from $x$ along $C$, but we consider
one edge at a time, and simultaneously remove
$P$ as it is colored. If $x\ne z$, then $z$ is
the farthest clockwise end of the path $P$ being colored;
the rest of $P$ (if any) has already been removed, and
our $x$ serves as Hartman's $x'$.

For those familiar with Hartman's proof: the one major difference between
our algorithm and Hartman's
occurs in Case~3.2.3.2 of the proof of Lemma~\ref{L:hartman3} below.
If we encounter a chord edge $zv\in E(G)-E(C)$
($z$ is the current end of $P$) with
$v\in C[z,y]$ and $L(z)\cap L(v)=\emptyset$ (i.e. $d\not\in L(v)$,
where $d$ is the color of $P$),
then instead of continuing to
search for neighbors of $z$ in $C[z,v]$ that we might add
to $P$, we
apply the inductive hypothesis such that $z$ now serves as
``$y$'' (see Figure~\ref{F:hartman_3_2_3} for a general illustration
of this case).
The edge from the vertex labeled $*$ to $y$ in
Figure~\ref{F:hartman_overview}
is an example of such a chord: our algorithm halts
$P$ at $*$, and divides the remaining subgraph at the chord,
see Figure~\ref{F:hartman_difference}.


Given a coloring $c$ of a graph $G$, and $v\in G$, we define
$\text{deg}_c(v)$
to be $\text{deg}(v)$ in the subgraph induced by $c(v)$'s color class,
i.e. the number of neighbors that share $v$'s color.

\begin{lemma}\label{L:hartman3}
Let $G$ be a biconnected, weakly triangulated plane graph with outer face
$C$. Let $x,y,z\in C$ be vertices (not necessarily distinct) such that
$z\in C[x,y]$. Let $L$ be a list assignment of $G$ such that
\begin{align*}
    |L(v)| &= 1 \text{ for } v\in\{x,y,z\},\\
    |L(v)| &\ge 2 \text{ for } v\in C-\{x,y,z\},\\
    |L(v)| &\ge 3 \text{ for } v\in G-C,
\end{align*}
and if $v\in C[x,z]-z$, then $L(v)\cap L(z)=\emptyset$.
There exists a path $L$-list-coloring $c$ of $G$ such that $\text{deg}_c(x)\le 1$,
$\text{deg}_c(y)\le 1$, and $\text{deg}_c(z)\le 1$. Moreover,
if $z=y$, or if $C[z,y]=z,y$ and $L(z)\cap L(y)=\emptyset$,
then $\text{deg}_c(z)=0$.
\end{lemma}

\begin{proof}
Suppose that $m=e(G)\le 1$. Then $G=C$. We define a path
$L$-list-coloring $c$ of $G$ as follows.
Let $c(x)\in L(x)$ and $c(y)\in L(y)$ be the color in
each respective list.
If $m=0$, then $n(G)=1$ and $c$ trivially satisfies the lemma.
Otherwise $m=1$ and $n(G)= 2$. If $x\ne y$, then $c$ is a
path $L$-list-coloring of $G$ with the constraints of the lemma.
Otherwise the remaining
$v\in G-y$ satisfies $|L(v)|\ge 2$, and we pick
$c(v)\in L(v)-\{c(y)\}$.

We proceed by induction on $m$, the number of edges. Let
$u_1,u_2,\ldots,u_k$ label the neighbors of $z$ in counter-clockwise
order such that $u_1$ is the vertex immediately counter-clockwise
from $z$ around $C$, and $u_k$ is the vertex clockwise from $z$ around $C$.
In each of the subsequent cases we will apply the lemma separately
to one or two subgraphs $G_1,G_2$ of $G$, with corresponding labeled
outer face vertices $x_i,y_i,z_i\in G_i$ for $i=1,2$.

\textbf{Case~1.}
Suppose that $u_1=y$. Note that $z=x$ since $z\in C[x,y]$. Therefore
$V(C[z,y])=V(C)$ and $|V(C[z,y])|\ge 3$, so $C[z,y]\ne z,y$.
Apply the lemma to find a path $L$-list-coloring $c$ of $G_1=G$ with
$x_1=y$, $y_1=x$, and $z_1=y$, see Figure~\ref{F:hartman_1} (left).

\textbf{Case~2.}
Suppose that $u_1\ne y$ and $z=x$. Then $u_1\in C-C[x,z]$
and $|L(u_1)|\ge 2$. Pick $d\in L(u_1)- L(z)$. Define
$L'(u_1)=\{d\}$ and $L'(v)=L(v)$ for each $v\in G-u_1$.
Find a path $L'$-list-coloring of $G_1=G$ with $x_1=u_1$,
$y_1=y$, and $z_1=z$, see Figure~\ref{F:hartman_1} (middle).

\textbf{Case~3.}
Suppose that $u_1\ne y$ and $z\ne x$. 
Our strategy will be to apply the inductive hypothesis to
the \defterm{blocks} (maximal biconnected subgraphs) of $G-zu_1$.
Because $u_1\in C[x,z]$, we have $L(u_1)\cap L(z)=\emptyset$.
Thus any path $L$-list-coloring of $G-zu_1$ is also a path $L$-list-coloring
of $G$. There are three cases to consider, see
Figures~\ref{F:hartman_1} (right), \ref{F:hartman_3_2},
and \ref{F:hartman_3_2_3}.

\textbf{Case~3.1.}
Suppose that $u_2\in G-C$. Define $L'(u_2)=L(u_2)- L(z)$ and
$L'(v)=L(v)$ for each $v\in G-u_2$. Note that $|L'(u_2)|\ge |L(u_2)|-1\ge 2$.
Let $C_1$ be the outer face of $G_1=G-zu_1$,
and observe that $C_1[x,z]$ is the union of $C[x,z]-u_1z$ with the
path $u_1,u_2,z$. Since $|L'(u_2)|\ge 2$ and $L'(u_2)\cap
L'(z)=\emptyset$, we may apply the inductive hypothesis
to find a path $L'$-list-coloring of $G_1$ with $x_1=x$, $y_1=y$, $z_1=z$.

\textbf{Case~3.2.}
Suppose that $u_2\in C$. Observe that $u_2$ is a \defterm{cut-vertex} of
$G-zu_1$, i.e. $G-zu_1-u_2$ is disconnected.
Define $C_1=C[u_2,u_1]\cup u_1u_2$ and
$C_2=C[z,u_2]\cup zu_2$. Let $G_1=\graphintc(C_1)$ and $G_2=\graphintc(C_2)$.
The subgraphs $G_1$ and $G_2$ are the two blocks of
$G-zu_1$. Note that if $k=2$, then $G_1=G-z$ and $G_2=z,u_2$.

In each subsequent case we will apply the inductive
hypothesis to find a path $L$-list-coloring $c_1$ of $G_1$ and a path
$L$-list-coloring $c_2$ of $G_2$ such that $c_1(u_2)=c_2(u_2)$. Let
$c$ be the $L$-list-coloring of $G$ defined by $v\mapsto c_1(v)$ for $v\in G_1$
and $v\mapsto c_2(v)$ for $v\in G_2$.
Observe that $\text{deg}_c(v)=\text{deg}_{c_1}(v)$
for each $v\in G_1-u_2$, $\text{deg}_c(v)=\text{deg}_{c_2}(v)$ for each
$v\in G_2-u_2$, and
$\text{deg}_c(u_2)=\text{deg}_{c_1}(u_2)+\text{deg}_{c_2}(u_2)$.
To show that $c$ is a path $L$-list-coloring of $G$ it suffices to show that
$\text{deg}_{c}(u_2)\le 2$. We'll also need to show that the
$\text{deg}_c$ constraints hold for $x,y,z$, but these will often follow
immediately from the inductive hypothesis.

$\text{deg}_{c_2}(u_2)\le 1$, thus $c$ is a path $L$-list-coloring of $G$.
Since $x_1=x$ in $G_1-u_2$, and $y_2=y$ and $z_2=z$ in $G_2-u_2$, $c$
satisfies the $\text{deg}_c$ constraints.

\textbf{Case~3.2.3.}
Suppose that $u_2\in C[z,y]$. Note that $z\ne y$.
There are two cases to consider, see Figure~\ref{F:hartman_3_2_3}.

\textbf{Case~3.2.3.1.} Suppose that $L(z)\cap L(u_2)\ne\emptyset$. Then 
either $u_2=y$ and $L(z)=L(y)$, or $C[z,y]\ne z,y$.
Define $L'(u_2)=L(z)$
and $L'(v)=L(v)$ for each $v\in G-u_2$. Find a path $L'$-list-coloring $c_1$ of $G_1$
with $x_1=x$, $y_1=y$, and $z_1=u_2$. Then find a path $L'$-list-coloring $c_2$ of
$G_2$ with $x_2=u_2$, $y_2=z$, and $z_2=u_2$. Since
$\text{deg}_{c_1}(u_2)\le 1$ and $\text{deg}_{c_2}(u_2)=1$, it follows
that $c$ is a path $L$-list-coloring of $G$. If $u_2=y$,
then $z_1=y_1=y$ and $\text{deg}_{c_1}(y)=0$; thus $\text{deg}_c(y)=1$.
So $\text{deg}_c(y)\le 1$ and
$c$ satisfies the constraints.

\textbf{Case~3.2.3.2.} Suppose that $L(z)\cap L(u_2)=\emptyset$. Find
a path $L$-list-coloring $c_1$ of $G_1$ with
$x_1=x$, $y_1=y$, and $z_1=x$. Define $L'(u_2)=\{c_1(u_2)\}$ and $L'(v)=L(v)$
for each $v\in G_2-u_2$. Then find a path $L'$-list-coloring $c_2$ of $G_2$
with $x_2=u_2$, $y_2=z$, and $z_2=u_2$. Because
$C[z_2,y_2]=z_2,y_2$ and $L'(z_2)\cap L'(y_2)=\emptyset$, we must have
$\text{deg}_{c_2}(u_2)=\text{deg}_{c_2}(z_2)=0$. Thus
$c$ is a path $L$-list-coloring of $G$.

Suppose $C[z,y]=z,y$. Then it must be that $u_2=y$ and $k=2$.
Therefore $G_2=z,y$ and $\text{deg}_c(z)=0$, since
$c(z)\not\in L(y)$. Thus $c$ satisfies the constraints of the lemma.
\ggcnopf

Let $G$ be a planar graph and $L$ a list assignment such
that $|L(v)|\ge 3$ for each $v\in G$. Compute a planar embedding and add
edges
to produce a triangulated plane graph $G'$. Pick $u\in G'$ on the outer face
and $d\in L(u)$. Define the list assignment $L'$ by
$L'(u)=\{d\}$ and $L'(v)=L(v)$ for $v\in G'-u$.
By Lemma~\ref{L:hartman3} there exists a path $L'$-list-coloring of $G'$,
and thus a path $L$-list-coloring of $G$.
So Theorem~\ref{T:planar3} follows immediately from 
Lemma~\ref{L:hartman3}.

The proof of Lemma~\ref{L:hartman3} describes a linear time
path list-coloring algorithm,
see Algorithm~\ref{A:hartman_impl}.
For $v\in G$ and $u\in N(v)$, we will assume that
$\nxt(\adj{v}{u})$, $\prv(\adj{v}{u})$, and $\adj{u}{v}$ can be
computed in constant time from $\adj{v}{u}$,
see augmented adjacency lists in Section~\ref{S:representation}.

\begin{algorithm}\label{A:hartman_impl} Path $3$-Choose

\textbf{Input.} Let $C$ be a cycle or length $1$ path in a
weakly triangulated plane graph $G$ represented via augmented
adjacency lists.
Let $x,y,z\in C$ be such that $z\in C[x,y]$.

Let $L$ be a length $n$ array of lists of colors
such that for $v\in\{x,y,z\}$ each list $L(v)$ has length one,
for $v\in C-\{x,y,z\}$ each list $L(v)$ has length two
or three, and for $v\in \graphinto(C)$ each list
$L(v)$ has length three. Furthermore, for each $v\in C[x,z] - z$, assume
that $L(v)$ does not contain the color in $L(z)$.

Let $A,B$ be length $n$ arrays such that for each $v\in C$ we have
$A(v)=\adj{v}{a}$ and $B(v)=\adj{v}{b}$, where
$a$ is the vertex
immediately clockwise from $v$ around $C$, and
$b$ is the vertex immediately counter clockwise
from $v$ around $C$.

Let $S$ be a length $n$ integer array such
that, for $v\in\graphintc(C)$, $S(v)\ne 0$ if and only if $v\in C$, and
$S(v)=S(x)$ if and only if $v\in C[x,z]-z$ (or $v=x=z$).

Let $\text{max}(S)=\text{max}_{v\in G} S(v)$ and
$m_C=e(\graphintc(C))$. Define $\ell=\text{max}(S)+r$, where $r$
is determined by the procedure case below that the input satisfies.
If $m_C=1$ (Base case) or $z\ne x$ (Case~3), then $r=0$.
If $z=x$ and $C[y,x]\ne y,x$ (Case~2), then $r=1$.
Otherwise $z=x$ and $C[y,x]=y,x$ (Case~1), and $r=2$. Assume that
$\ell < 2(m-m_C+1) + 2$.

Let $M$
be a length $2m+2$ integer array such that if $v\in C$,
then $M(S(v))=S(y)$ if and only if $v\in C[z,y]$.

The concrete input will be $G$, $L$,
$A$, $B$, $S$, $M$, and the tuple $(x,y,z)$.

\textbf{Output.} For each $v\in\graphintc(C)$, all but one color will be
removed from the list $L(v)$. The remaining color in each list will represent
a path $L$-list-coloring of $\graphintc(C)$
such that $\text{deg}_c(x)\le1$, $\text{deg}_c(y)\le1$, and
$\text{deg}_c(z)\le1$. If $z=y$, or if $C[z,y]=z,y$ and $L(z)$ did
not contain the color in $L(y)$, then $\text{deg}_c(z)=0$. Moreover,
afterwards $\text{max}(S)\le\ell+2(m_C-1)$.

\textbf{Procedure.} Let $\adj{z}{u_1}:= B(z)$. Our strategy
will follow the proof of Lemma~\ref{L:hartman3}.

\textbf{Base case.} If $A(z)=B(z)$, then $C=z,u_1$
is a length $1$ path. If $u_1\ne x$ and $u_1\ne y$, remove the
color in $L(z)$ from $L(u_1)$, if it exists, then remove further colors
until one color remains. Note that
$m_C=1$ and $\text{max}(S)\le\ell+ 2(m_C-1)=\ell$ by definition.

\textbf{Recursive case.} Suppose that $A(z)\ne B(z)$.
Let $\adj{z}{u_2}:=\nxt(\adj{z}{u_1})$. It follows from the
definition of $\ell$
that $\text{max}(S)\le\ell+2(m_C-1)$ after Cases~1, 2,
and 3.1, so we will only argue why the bound
holds after Case~3.2.
It may be useful to see
Figures~\ref{F:hartman_1}, \ref{F:hartman_3_2}, and
\ref{F:hartman_3_2_3}.

\textbf{Case~1.} Suppose that $u_1=y$. Then $z=x$, since $z\in C[x,y]$.
Set $S(x)\leftarrow \text{max}(S)+1$ and
$S(y)\leftarrow S(x)$.
Assign $M(S(x))\leftarrow S(x)$.
Make a recursive call with the input $(y, x, y)$.

\textbf{Case~2.} Suppose that $z=x$ and $u_1\ne y$. 
Remove the color in $L(z)$ from $L(u_1)$, if it exists, then remove
further colors until one color remains.
Assign $S(u_1)\leftarrow \text{max}(S)+1$
and $M(S(u_1))\leftarrow S(u_1)$,
and make a recursive call with input $(u_1, y, z)$.

\textbf{Case~3.} Suppose that $z\ne x$ and $u_1\ne y$.
Remove $zu_1$ by assigning $A(u_1)\leftarrow\prv(\adj{u_1}{z})$
and $B(z)\leftarrow\nxt(\adj{z}{u_1})$.

\textbf{Case~3.1.} Suppose that $S(u_2)=0$, i.e. $u_2\in
\graphinto(C)$. Assign $S(u_2)\leftarrow S(x)$, and initialize
$B(u_2)\leftarrow\adj{u_2}{u_1}=\nxt(\adj{u_2}{z})$ and
$A(u_2)\leftarrow\adj{u_2}{z}$,
see Figure~\ref{F:hartman_1} (right).
Remove the color in $L(z)$ from
$L(u_2)$.
Make a recursive call with the same input $(x, y, z)$.

\textbf{Case~3.2.} Suppose that $S(u_2)\ne 0$, i.e. $u_2\in C$. Just as in
Case~3.2 of the proof of Lemma~\ref{L:hartman3}, we will separately consider
the two blocks $G_1$ and $G_2$ of $\graphintc(C)-zu_1$.
Note that $m_C-1=e(G_1)+e(G_2)$.

As we've already removed the edge $zu_1$ by
adjusting $B(z)$ and $A(u_1)$, it remains
to ``split'' the
neighborhood of $u_2$ at the edge $\adj{u_2}{z}$ such that the recursive
call on $G_1$ considers only the neighbors of $u_2$ counter-clockwise
from $z$, and the call
on $G_2$ considers $z$ and all neighbors clockwise from $z$;
refer
to Figure~\ref{F:hartman_3_2} and
Figure~\ref{F:hartman_3_2_3}.

Let $\adj{u_2}{a}:= A(u_2)$ and $\adj{u_2}{b}:= B(u_2)$.
To represent $G_1$, assign 
$A(u_2)\leftarrow\adj{u_2}{a}$ and
$B(u_2)\leftarrow\nxt(\adj{u_2}{z})$.
To represent $G_2$,
assign
$A(u_2)\leftarrow\adj{u_2}{z}$ and
$B(u_2)\leftarrow\adj{u_2}{b}$

\textbf{Case~3.2.1.} Suppose that $S(u_2)=S(x)$, i.e. $u_2\in C[x,z]$. Make a
recursive call on $G_2$ with input $(x, y, z)$;
afterwards $\text{max}(S)\le\ell + 2e(G_1)-2$.
Assign $S(u_2)\leftarrow\text{max}(S)+1$ and
$M(S(u_2))\leftarrow S(u_2)$, and make a recursive call
on $G_1$ with input $(u_2, u_2, u_2)$.
Finally, observe that
$\text{max}(S)\le\ell + 2e(G_1)-2 + 1 + 2e(G_2)-1<\ell+2(m_C-1)$.

\textbf{Case~3.2.2.} Suppose that $S(u_2)\ne 0$, but
$S(u_2)\ne S(x)$ and $M(S(u_2))\ne S(y)$. In other words, suppose that
$u_2\in C[y,x]-x-y$.
First remove the color in $L(z)$ from $L(u_2)$, if it exists, then remove
colors until only one remains. Set $S(u_2)\leftarrow S(x)$.
Make a recursive call on $G_1$ with input $(x, u_2, x)$;
afterwards $\text{max}(S)\le\ell +2e(G_1)$.
Set $S(u_2)\leftarrow\text{max}(S)+1$ and
$M(S(u_2))\leftarrow S(u_2)$, and
make a recursive call on $G_2$ with input $(u_2, y, z)$.
Finally, observe that
$\text{max}(S)\le\ell + 2e(G_1) + 1 + 2e(G_2)-2<\ell+2(m_C-1)$.

\textbf{Case~3.2.3.} Suppose that $M(S(u_2))=S(y)$, i.e.
$u_2\in C[z,y]$. There are
two cases to consider, see Figure~\ref{F:hartman_3_2_3}.

\textbf{Case~3.2.3.1.} Suppose that the color in $L(z)$ is in $L(u_2)$. Remove
all colors from $L(u_2)$ except for the color in $L(z)$.
Make a recursive call on $G_1$ with input $(x, y, u_2)$;
afterwards $\text{max}(S)\le\ell + 2e(G_1)-2$.
Assign
$S(z)\leftarrow\text{max}(S)+1$, $S(u_2)\leftarrow S(z)$,
and $M(S(z))\leftarrow S(z)$. Make a
recursive call on $G_2$ with input $(u_2, z, u_2)$. Finally, observe that
$\text{max}(S)\le\ell + 2e(G_1)-2 + 1 + 2e(G_2) - 1<\ell+2(m_C-1)$.

\textbf{Case~3.2.3.2.} Suppose that the color in $L(z)$ is not in $L(u_2)$.
Assign $M(S(x))\leftarrow S(y)$. Make a recursive call on $G_1$
with input $(x, y, x)$; afterwards $\text{max}(S)\le\ell + 2e(G_1)$.
Assign $S(z)\leftarrow\text{max}(S)+1$, $S(u_2)\leftarrow S(z)$, and
$M(S(z))\leftarrow S(z)$. Make a
recursive call on $G_2$ with input $(u_2, z, u_2)$. Observe
$\text{max}(S)\le\ell + 2e(G_1) + 1 + 2e(G_2) - 1=\ell+2(m_C-1)$.

Note that this is the only case where
$M(S(v))$ is set a value other than $S(v)$.
Setting $M(S(x))\leftarrow S(y)$ effectively ``joins''
$C[x,u_1]$ onto $C[u_2,y]$ to represent $C_1[z_1,y_1]$ in $G_1$,
see Figure~8.
Without the array $M$, we'd need to re-mark each $v\in C[x,u_1]$ with
$S(v)\leftarrow S(y)$.
\end{algorithm}

Let $G$ be a triangulated plane graph
represented by augmented adjacency
lists. Let $L$ be a length $n$ array of color lists of length $3$,
representing a list assignment of $G$. We may path $L$-color $G$ using
Algorithm~\ref{A:hartman_impl} as follows.

Create length $n$ arrays $A,B$ and initialize $A(v)$ and $B(v)$
for each $v\in C$ on the outer face of $G$.
Create a length $n$ integer array
$S$ and initialize $S(v)\leftarrow 1$ for each $v\in C$ and
$S(v)\leftarrow 0$ for each $v\in G-C$. Pick any $u\in C$,
assign $S(u)\leftarrow 2$, and remove all but one color from $L(u)$.
Create a length $2m+2$ array of integers $M$ and initialize
$M(i)\leftarrow i$ for each $i\in\{0,1,2\}$.
Finally, apply Algorithm~\ref{A:hartman_impl} with the input $G$, $L$,
$A$, $B$, $S$, $M$, and $(u, u, u)$. The remaining color in each
list in $L$ will represent a path $L$-list-coloring of $G$.

Each case in Algorithm~\ref{A:hartman_impl} performs a fixed number
of constant time operations. Case~3 removes an edge
from the subgraph(s) under consideration.
Case~1 makes a recursive call
with an input that satisfies Case~2, and Case~2 makes a recursive
call with an input that satisfies Case~3.
Therefore the total number of recursive calls made, and thus the
overall time complexity,
is $\mathcal{O}(n)$. See Figures~\ref{F:hartman_impl} and
\ref{F:hartman_impl_cont} for a concrete example.

\section{Experimental Performance and Parallelism}\label{S:performance}

A C implementation of each algorithm is available~\cite{Bro2017}.
For each $i$ from $4\ldots 7$, a uniform random sample of $100$
plane triangulations of order $10^i$ was
generated using the method of
Poulalhon and Schaeffer~\cite{Pou2006}. 
Each algorithm, as well as a baseline breadth-first search (BFS),
was run on the sample set; see Figure~\ref{F:plot}.

In Algorithm~\ref{A:poh_linear} and Algorithm~\ref{A:hartman_impl}, it
is possible to maintain a
stack of independent recursive frames, and to have a pool of threads execute them
concurrently. The amount of parallelism possible using this method
greatly varies depending on the graph structure, but a
2-3x average performance
gain (2.8x for Alg.~\ref{A:poh_linear}, and 2.4x for Alg.~\ref{A:hartman_impl})
was observed when using 4 threads to path color large random triangulations,
see Figure~\ref{F:plot}.

Our parallel implementation of Algorithm~\ref{A:poh_linear} maintains a
shared lock-guarded stack which all threads may push/pop recursive
frames to/from.

To reduce lock contention, each thread also
maintains a
small local stack of frames, and only accesses the shared
stack when their local stack is full or empty.

Algorithm~\ref{A:hartman_impl} is trickier to adapt to
parallel execution: the recursive calls in Case~3.2
rely on a sequential execution order.
If we save a local copy of
$S(v), A(v), B(v)$ for each $v\in\{x, y,z\}$ alongside
each frame, then the recursive calls in
Case~3.2.1 with $u_2=x$, Case~3.2.2,
Case~3.2.3.1, and Case~3.2.3.2 with $u_2=y$ become fully independent.
However, in Case~3.2.1 with $u_2\ne x$, and Case~3.2.3.2 with $u_2\ne y$,
the second call will always depend on the color of $u_2$ (the one color
remaining in $L(u_2)$)
computed by the first call.

Our parallel implementation of Algorithm~\ref{A:hartman_impl}
maintains a shared object pool
of frames and a shared stack of references to frames in the pool.
Frames are added to
the pool in the usual course of the algorithm, but
only pushed to the stack if they are ready to execute.
For each $v\in G$, we store an optional reference
to a frame that will become ready when $v$ has been colored. To allow for
multiple frames to await the coloring of one vertex, each frame in the
pool stores an optional reference to a ``next frame in line''
(i.e. an ``intrusive'' linked list).
When a vertex $v$ is colored, each frame waiting on $v$
is pushed to the stack.
